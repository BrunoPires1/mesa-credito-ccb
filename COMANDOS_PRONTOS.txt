═══════════════════════════════════════════════════════════════
  COMANDOS PARA COPIAR E COLAR NO TERMINAL
═══════════════════════════════════════════════════════════════

PASSO 1: Abra o terminal nesta pasta
PASSO 2: Copie e cole cada comando abaixo (um por vez)
PASSO 3: Pressione ENTER após cada comando

═══════════════════════════════════════════════════════════════

git init

git add .

git commit -m "Sistema otimizado"

git remote add origin SUA-URL-DO-GITHUB-AQUI

git push -u origin main

═══════════════════════════════════════════════════════════════

⚠️ IMPORTANTE: No 4º comando, substitua "SUA-URL-DO-GITHUB-AQUI" 
pela URL do seu repositório GitHub!

Exemplo:
git remote add origin https://github.com/brunopires/mesa-credito.git
